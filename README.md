# Taumasyang Utility

## 安装方式

直接安装本 Tap 中的应用程序，

```sh
brew install taumasyang/utility/<token>
```

或者先克隆 Tap，之后可以省略前缀。

```sh
brew tap taumasyang/utility
brew trust taumasyang/utility
brew install <token>
```
